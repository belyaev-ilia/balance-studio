# Balance & Progression Studio

Веб-сервис для проверки баланса игры, созданный в рамках учебного кейса. Написан на чистом HTML/CSS/JS (vanilla JS), не требует сервера и базы данных. Все данные сохраняются в браузере (localStorage).

## Ссылка на работающий сервис
https://belyaev-ilia.github.io/balance-studio/

## Реализованные модули (MVP)
1. **Импорт данных:** загрузка CSV/JSON, валидация обязательных колонок, числовых типов и дублей ID.
2. **Редактор таблицы:** редактирование характеристик, добавление и удаление юнитов, автосохранение в localStorage.
3. **Калькулятор урона / TTK:** расчет урона по формуле (Атака - Защита) и расчет времени до убийства.
4. **Кривая прогрессии:** настройка формулы опыта (База * Множитель^Уровень), таблица уровней и график (Chart.js).
5. **Проверка лута:** таблица дропа, валидация суммы вероятностей (ровно 100%), подсветка ошибок, экспорт JSON.

## Как запустить локально
1. Скачайте файлы `index.html`, `style.css`, `app.js`.
2. Положите их в одну папку.
3. Откройте файл `index.html` в любом браузере.
